判断条件怎么写

写法 含义
a == b 相等
a != b 不相等
a > b / a <= b 大小比较
x in [1, 2, 3] 在不在里面
s and t / s or t / not s 且 / 或 / 非

新手最容易犯的错：= 是赋值，== 才是比较。if x = 1: 直接语法报错，这点反而安全；危险的是 if x == 1 写成了 if x = 1 的那种思路混乱。

还有一点值得早点知道：空值、0、空字符串、"空"的容器，在条件里都算假。

所以判断"有没有拿到东西"，直接 if result: 就够，不用写 if result != None。
