一、Python 是什么

Python 是一门解释型、面向对象、动态类型的编程语言，特点是语法接近自然语言，入门门槛低，同时生态极强（数据分析、爬虫、Web、自动化、AI 都用它）。

特点 说明
解释执行 不用编译，写完直接运行
动态类型 变量不用声明类型，赋值时自动确定
缩进敏感 用缩进（4 个空格）表示代码块，不用大括号
生态丰富 pip install 就能装十万+ 第三方库

为什么新手常被缩进绊到：Python 用缩进划分代码块，缩进错了程序直接报错 IndentationError，这在其他语言里很少见。

二、第一个程序和注释

注释：写给人看的说明，程序执行时会被忽略。

原则：注释解释"为什么这么写"，而不是"这行在做什么"——x = x + 1 # x 加 1 这种注释是废话。

三、变量

变量就是给数据起个名字，方便后面反复使用。

命名规则（记这几条就够）：

规则 正确 错误
只能字母、数字、下划线 user_name user-name
不能以数字开头 num1 1num
区分大小写 Age 和 age 是两个变量 —
不能用关键字 my_class class

约定：变量名用小写 + 下划线（user_name），常量用全大写（MAX_SIZE）。这不是语法要求，但团队协作里必须统一。

延伸：变量其实是什么

Python 的变量不是"装数据的盒子"，而是贴在数据上的标签。a = b = [1, 2] 时，a 和 b 指向同一个列表，改一个另一个也变——这是新手最容易踩的坑之一。

str 字符串（引号包起来） "你好"、'abc'
bool 布尔值 True、False
NoneType 空值 None
