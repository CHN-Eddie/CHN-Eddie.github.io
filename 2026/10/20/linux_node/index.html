基础篇

Linux 介绍

Linux是一个开源、免费的操作系统,就像我们熟知的Windows和macOS一样。它是计算机硬件（如CPU、内存、硬盘）和用户（或应用程序）之间的桥梁，负责管理所有硬件资源，并提供软件运行的环境。其在稳定性、安全性以及处理多并发方面都有独特优点。

Linux 目录结构

  • / （根目录）
    Linux目录采用的树状结构，所有目录都挂载在 / 根目录下，是所有目录以及文件的起点，是绝对路径的开始。
    （绝对路径：是指从文件系统的根目录开始并且到目标文件或者目录的路径；相对路径：指从当前所在目录开始到目标文件或者目录的路径）

  • /bin （binary 二进制目录）
    /bin目录存放系统的可执行程序，所有用户均可执行。

  • /sbin （system binary 系统二进制目录）
    /sbin目录存放系统管理的可执行程序，通常需要root权限执行。
    （root：是操作系统中权限最高的超级管理员用户）

  • /etc （editable text configuration 可编辑文本配置目录）
    /etc目录存放这系统的配置文件。

  • /home （家目录）
    /home目录为普通用户的主目录，每个普通用户都在 /home 下有一个与用户名相同的子目录。

  • /root （root用户的主目录）
    /root目录为root用户（超级管理员）的主目录，仅root用户可以访问。

  • /usr （user system resources）
    /usr目录为用户系统资源目录，一般存放系统软件资源。

  • /var （variable）
    /var目录一般存放动态文件，如日志、缓存、临时文件等。

  • /tmp （temporary）
    /tmp目录存放临时文件，所有用户均可读写，重启后文件可能会被清理。

  • /dev (device)
    /dev目录存放设备文件，Linux系统的所有硬件设备（硬盘、键盘、打印机等）均以文件显示。有一句话叫“Linux一切皆文件”

  • /proc （process）
    /proc目录为虚拟文件系统，存放系统进程和内核信息，其中的文件内容是动态生成。

  • /sys （system）
    /sys目录为虚拟文件系统，存放硬件设备和内核驱动的相关信息，一般用于管理硬件状态。

  • /boot （启动目录）
    /boot目录存放系统启动相关文件，如内核文件（vmlinuz）、引导程序配置（grub）等。一般不要手动改动，改坏了系统开不了机

  • /lib （library 库目录）
    /lib目录存放系统启动和运行所需的共享库文件（相当于Windows里的 .dll 文件），/bin 和 /sbin 里的程序依赖它们。

  • /opt （optional 可选目录）
    /opt目录一般用于安装第三方软件，很多手动安装（非包管理器）的软件会放在这里，比如 /opt/google/chrome。

  • /mnt （mount 挂载目录）
    /mnt目录用于临时挂载其他文件系统，比如临时挂载一块U盘、一个网络共享。手动挂载时常用

  • /media （媒体目录）
    /media目录用于自动挂载可移动设备（U盘、移动硬盘、光盘），桌面版系统会自动在这里生成挂载点。

  • /srv （service 服务目录）
    /srv目录存放服务类程序的数据，如网站文件、FTP 数据等。现在很多发行版不再强制使用

  • /run （运行时目录）
    /run目录存放系统本次运行期间的临时数据（进程PID、锁文件、socket），内存中，重启即清空。

  • /lost+found （找回目录）
    /lost+found目录是文件系统损坏修复后，找回的碎片文件会被放在这里。没有异常时可以忽略

目录速查表

目录 作用 记忆点
/ 根目录，一切路径的起点 树根
/bin 普通用户可用的命令 binary
/sbin 管理员用的命令 system binary
/etc 配置文件 改配置来这里
/home 普通用户的家 你的文件都在这
/root 管理员的家 只有root能进
/usr 系统软件资源 装好的程序大多在这
/var 会变化的数据 日志在看这里
/tmp 临时文件 重启可能清空
/dev 设备文件 一切皆文件
/proc 进程与内核信息 虚拟的，不占硬盘
/sys 硬件与驱动信息 虚拟的，调硬件
/boot 内核与引导 别乱动
/lib 共享库 程序运行依赖
/opt 第三方软件 手动装的常在
/mnt / /media 挂载点 插U盘看这里

一句话记住：配置去 /etc，日志去 /var/log，自己的东西放 /home，装好的软件在 /usr，临时用的放 /tmp。

Linux 与 Unix 的关系

Linux 是"类 Unix"系统：命令和设计思想跟 Unix 一脉相承，但代码是独立写的、开源免费。所以学会 Linux，换到 Unix 也能用

为什么用 Linux 做服务器

领域 说明
服务器 企业网站、数据库、云服务大多跑 Linux
嵌入式 路由器、机顶盒、车载系统
移动端 Android 内核就是 Linux

虚拟机的三种网络模式（VMware）

注意区分：这里讲的是「虚拟机怎么和外界网络连接」（桥接/NAT/仅主机），不是「宽带、WiFi、5G 怎么接入互联网」——那是另一回事。

虚拟机装好后，第一件事是选网络模式。VMware 有三种，区别在IP 从哪来、谁能访问它：

模式 虚拟网卡 IP 从哪来 能上网 谁能访问虚拟机 注意
桥接（Bridged） VMnet0 路由器 DHCP，和宿主机同网段 ✅ 局域网里任何机器 需要网络有 DHCP；无线网卡有时不支持；IP 可能冲突
NAT VMnet8 VMware 自己的 DHCP（192.168.x.x 私有段） ✅（经宿主机转发） 只有宿主机，外部要端口映射 换 WiFi、换 IP 都不影响它，学习最省事
仅主机（Host-only） VMnet1 VMware 自己的 DHCP ❌ 只有宿主机 完全隔离，适合试危险软件

另外还有「自定义（VMnet2~VMnet19）」和「LAN 区段」，属于进阶用法，一般用不到。

怎么记

学习阶段选哪个

选 NAT。 理由：

  • 换网络（公司/家里/热点）不用改配置
  • 虚拟机 IP 固定在那个私有段里，SSH 连它不会变
  • 能上网装软件、yum install 都正常

桥接适合"要把虚拟机当局域网服务器给手机/其他电脑访问"的场景

远程登录

服务器不接显示器，都在机房/云上，要在自己电脑上远程操作。

  • 第一次连接输入 yes 接受指纹
  • 输入密码时屏幕不显示任何字符，是正常的

常用工具：XShell（Windows）、MobaXterm、macOS 自带终端。

远程文件传输

传文件到服务器有两种命令行方式，都用 22 端口，都是加密的。

一、scp（一条命令拷完，最常用）

特点：像 cp 一样，一条命令说完就完事。适合"我就传一个文件"。

二、sftp（交互式，像 FTP 一样浏览）

进去以后常用命令：

命令 作用
ls / cd / pwd 查看、切换远程目录
lls / lcd / lpwd 查看、切换本地目录（l = local）
put 文件 上传
get 文件 下载
put -r 目录 / get -r 目录 传目录
reput / reget 断点续传
exit 或 bye 退出

特点：可以先 ls 看看到底有哪些文件，再决定传什么。适合"我不确定路径、想先浏览一下"。

三、两者怎么选

对比 scp sftp
用法 一条命令 交互会话
浏览远程目录 ❌ 不行 ✅ 可以
断点续传 ❌ 不支持 ✅ reput / reget
写脚本批量传 ✅ 方便 ✅ 也行
传大文件断了 得从头再来 可以续传

实际经验：日常传一两个文件用 scp；传大文件（几百 MB 的备份）用 sftp + 续传，断了不用重来。

四、图形工具（不想敲命令）

工具 平台 说明
XFTP Windows 和 XShell 配套，左边本地右边远程，拖拽即可
FileZilla Win/Mac/Linux 免费开源，协议选 SFTP
Cyberduck Mac Mac 上比较顺手
Termius 全平台 带 SFTP 面板的 SSH 客户端

Mac 用户注意：Finder 里"前往 → 连接服务器"填 sftp://user@IP 也能直接挂载成磁盘（但 Mac 自带只支持读取，写入要用第三方）。

vi / vim 快速入门

改服务器配置文件基本都用它。记住三种模式就能上手：

模式 怎么进 干什么
命令模式（默认） 打开就是 移动、删除、复制
插入模式 按 i 打字
底行模式 按 : 保存、退出、查找

保存 / 退出：四种组合（重要）

在命令模式下按 : 进入底行模式，然后：

命令 作用 什么时候用
:wq 保存并退出 改完要留
:w 保存，不退出 想接着改
:q 退出（没改动才行） 只是看看，没动手
:q! 不保存，强制退出 ⭐ 按错键、误删了、不想留改动

回车才生效（:q! 输完要按 Enter）。

按错了怎么办（新手必看）

场景：想看看配置文件，手一滑按了 x（删掉一个字符），或者按了 dd（删一整行），屏幕都变了，慌了。

三步走：

千万别按 :wq —— 那会把误删的内容写进文件，配置文件一坏服务就起不来。

如果改动其实是想要的

（u 是撤销上一步，改错了可以先按几下 u 回退，再决定 :wq 还是 :q!）

必会操作（命令模式下）

按键 作用
dd 删一整行
yy 复制一整行
p 粘贴
u 撤销
/关键字 搜索，n 跳下一个
gg / G 跳到首行 / 末行

新手最常懵的点：打开文件直接打字没反应 —— 因为你在命令模式，要先按 i。
